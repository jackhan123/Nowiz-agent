# Newiz 项目文件结构说明文档

## 📋 项目概览

**项目名称**: Newiz - AI 硬件实验室  
**项目类型**: 全栈 Web 应用 (Next.js + Flask)  
**主要功能**: AI 驱动的硬件设计和 BOM 生成平台  
**技术栈**: React, Next.js, TypeScript, Python, Flask, Tailwind CSS

## 🔧 核心文件详细说明

### 📱 前端核心文件

#### `app/page.tsx` - 主页面
- **功能**: 应用主入口页面
- **技术**: React + TypeScript
- **特点**: 响应式设计，AI 硬件生成界面

#### `app/api/generate-hardware/route.ts` - 硬件生成 API
- **功能**: 处理硬件设计请求
- **集成**: OpenAI API 调用
- **输出**: 完整硬件方案 + BOM 清单

#### `app/api/crystal-ball/route.ts` - 水晶球 API
- **功能**: 智能预测和建议
- **技术**: AI 驱动的预测分析

### 🐍 后端核心文件

#### `app.py` - Flask 主应用
- **功能**: Python 后端服务
- **API**: 硬件生成相关接口
- **集成**: 阿里云通义千问 API

#### `mock_pi.py` - 树莓派模拟器
- **功能**: 模拟树莓派硬件行为
- **用途**: 开发测试阶段使用
- **特性**: 完整的 GPIO 模拟

### 🌐 HTML 页面文件

#### `hardware-lab-final_v1.0_GOLDEN.html` - 黄金标准版本
- **状态**: ✅ 已批准的最终版本
- **设计**: Nowiz 风格 (黑白灰)
- **功能**: 3D 架构预览 + AI 聊天界面

## 🛠️ 开发环境设置

### 必需软件
- Node.js (v18+)
- Python (v3.8+)
- Git

### 环境配置
1. **前端环境**:
   ```bash
   npm install
   npm run dev
   ```

2. **后端环境**:
   ```bash
   pip install -r requirements.txt
   python app.py
   ```

### 环境变量配置
```bash
# .env.local
OPENAI_API_KEY=your-api-key
OPENAI_API_ENDPOINT=https://api.openai.com/v1/chat/completions
OPENAI_MODEL_NAME=gpt-4
```
